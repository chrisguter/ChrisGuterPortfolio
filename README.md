---

## 📌 Overview

This web portfolio is built to reflect who I am as a frontend developer — focused on performance, clean design, and user experience.  
It features:

- A multilingual interface with seamless language switching
- A showcase of selected projects and technical skills
- A mobile-first, responsive design
- Automated deployment via GitHub Actions
- Custom domain integration

---

## 🚀 Features

- 🔍 **Professional summary** and tech stack overview
- 💼 **Highlighted projects** with links and descriptions
- 🌍 **Multilingual support** using `react-i18next`
- 📱 **Fully responsive design** for desktop, tablet, and mobile
- 📬 **Contact form and social links**
- 🔄 **CI/CD pipeline** using GitHub Actions

---

## 🛠 Tech Stack

- ⚛️ **React** with Hooks
- ⚡ **Vite** for fast development and build times
- 🎨 **Tailwind CSS** for utility-first styling
- 🌐 **react-i18next** for internationalization
- 🤖 **GitHub Actions** for automated deployment

---

## 📦 Deployment

This project is deployed to **GitHub Pages** using a GitHub Actions workflow.  
A custom domain is configured: [https://chrisguter.com](https://chrisguter.com)
